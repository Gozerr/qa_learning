# QA Guide

Бесплатная карта знаний и практики для самостоятельного изучения тестирования ПО.
Проект не является онлайн-школой, платным курсом или сервисом трудоустройства.

## Что умеет сайт

- учебный маршрут из 11 тем: от основ тестирования до автоматизации;
- полноценные статьи с определением, объяснением, примерами, типичными ошибками и практическим заданием;
- поиск по заголовкам, описаниям и содержимому статей;
- связанные темы и переходы между предыдущей/следующей статьёй;
- отметка пройденных тем и прогресс в `localStorage`;
- отдельные карточки практики и инструментов с внешними ссылками;
- адаптивная версия от 320px без горизонтального скролла;
- GitHub Pages без обязательной регистрации и серверной базы.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический сервер:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Структура

- `index.html` — семантическая разметка страницы и основные секции.
- `styles.css` — адаптивная визуальная система QA Guide.
- `app.js` — учебные данные, рендер статей, поиск, навигация и прогресс.
- `supabase-setup.sql` — историческая заготовка предыдущей закрытой версии; текущая публичная версия её не использует.

## Публикация

Изменения в ветке `main` публикуются workflow `.github/workflows/deploy.yml` через GitHub Pages.
